About Me

I'm a developer interested in software development beyond a single platform or domain.

I started with front-end development and have worked with React and TypeScript, but I'm currently focusing on C# and .NET to build a stronger foundation in programming and software development.

My goal is to use C# and the .NET ecosystem as a foundation for exploring different areas of development — with backend development being one of them, alongside other fields I may pursue in the future.

I enjoy learning by building real projects, understanding how things work under the hood, and gradually expanding the range of problems I can solve with code.
